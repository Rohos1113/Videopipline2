# Change: voice-lab

**Дата:** 2026-11-15
**Основание:** запрос владельца — клонировать голоса по API ElevenLabs, сохранять их, использовать; нужен комплексный интерфейс выбора голоса (меню, кнопки, механики).

## Why

Выбор голоса сейчас размазан по четырём несвязанным местам, и ни одно не умеет свои голоса:

- нода «Озвучка» — нативный `<select>` с тремя `optgroup`, каталог импортируется из бандла (`web/src/components/studio/node-step-params-panel.tsx:265-294`, `web/src/lib/elevenlabs-voices.ts`);
- модалка библиотеки — тоже локальный JSON, 200 голосов, `fetch` внутри нет (`web/src/components/outsee/voice-library-modal.tsx:6,18`);
- Create KIE — тот же JSON, значение живёт в `useState` и никуда не сохраняется (`web/src/components/outsee/outsee-create-workspace.tsx:985,5003-5007`);
- монтаж — загрузка файла «Голос с компьютера» в `audio/voice_full.*`, другой механизм (`web/src/components/canvas/assemble-montage-board.tsx:1223-1283`).

Своих (клонированных) голосов нет ни в одном слое: в `app/models.py` класса `Voice` нет, в `app/web/routers/voices.py` только `catalog` / `{id}` / `{id}/sample`, обращения `/v1/voices/add` нет во всём репозитории, цены обучения нет ни в `media_spend.py`, ни в `media_prices.json`.

Технически клон уже прошёл бы: `resolve_elevenlabs_voice_id` принимает любую строку ≥15 символов (`app/services/elevenlabs_voices.py:88-89`), TTS берёт `voice_id` из `meta.node_step_params.audio` (`app/bots/elevenlabs_api.py:247-301`). Но выбрать клон в интерфейсе нельзя, а проверка живости голоса в WaveSpeed-ветке знает только 9 стандартных + 200 каталожных id (`app/services/elevenlabs_voices.py:102-109`) — клон там окажется «недоступен».

Отдельно: образцов на диске нет вовсе. `data/voices/samples` на этой машине отсутствует, фолбэки `C:\Users\EternalFlow\...` (`app/services/ru_voices.py:17-18`) тоже — `GET /api/voices/{id}/sample` отдаёт 404 на любой id, кнопка «Образец» в ноде молчит.

Цель: один раздел «Голоса» (Voice Lab) — клонирование, реестр сохранённых голосов, единый выбор для всех мест генерации.

## Решения владельца, без которых код не пишем

1. **Роли.** Клонирование — инструмент владельца (роль `admin`): кнопка «Клонировать голос» и все ручки `/api/voice-lab/*` видны и доступны только админу. Сама модалка «Голоса» и выбор из каталога остаются участнику, как сейчас (`/api/voices` уже в продуктовой поверхности, `app/web/identity.py:148-149`). Причина: ToS ElevenLabs запрещает «Making Available» (встраивание самого сервиса TTS в продукт для конечных пользователей) на Free/Starter/Creator/Pro, это открывается со Scale (`docs/SAAS-PIVOT.md:1276-1280`). Клонирование участником = прямой доступ к генерации голоса → смена тарифа. Клонирование силами студии, готовый ролик клиенту — прежний режим.
2. **Сеть.** `api.elevenlabs.io` из РФ недоступен: docs и API уводят на `https://geo-restriction.elevenlabs.io`, Россия в списке запрещённых стран. Нужен прокси или VPS-relay (по образцу `deploy/gpt-relay/README.md`). Вводим `ELEVENLABS_PROXY_URL`: сейчас прокси есть только в неиспользуемом модуле `app/services/elevenlabs_api.py:160-163,300-307`, а живой TTS-модуль `app/bots/elevenlabs_api.py` его не поддерживает.
3. **Персональные данные.** Сэмплы голоса человека — PII. Храним на диске студии, при создании обязательна галочка «голос мой или есть письменное разрешение диктора», при удалении сэмплы стираются вместе с записью.
4. **Тариф.** Клонирование — платная функция ElevenLabs (мгновенное клонирование с младших платных планов, профессиональное обучение — со старших). Порог проверяется живым запросом на Этапе 0; если доступа нет — фича не начинается.

## Architecture & Components

### 1. Хранение

- **Реестр первой версии — JSON, а не таблица**: `data/voices/clones/index.json` плюс каталоги `data/voices/clones/<uuid>/` (`meta.json`, `sample-N.<ext>`). Миграции и таблицы `voice_profiles` нет осознанно: записей единицы, связей с проектами не нужно, риск миграции больше пользы. Появится продуктовый доступ участнику — отдельный change с таблицей, `tenant_id` и RLS (конституция AR-2).
- Арендатора в реестре нет: это инструмент владельца, как `prompt_library`.
- Диск: `data/voices/clones/<uuid>/sample-01.mp3`, превью рядом. Каталог `data/voices` уже известен коду (`app/services/ru_voices.py:16`, учтён в подсчёте места `app/web/routers/storage.py:132`).
- Источник правды — аккаунт ElevenLabs. Синхронизации (`POST /api/voice-lab/sync`) в первой версии нет: реестр пишется только студией. Удаление записи стирает каталог с сэмплами; голос в аккаунте провайдера не трогается.

### 2. Клиент провайдера — `app/bots/elevenlabs_clone.py` (сделано)

- `create_voice(name, description, files)` → `POST /v1/voices/add` (multipart, заголовок `xi-api-key`), ответ `voice_id`.
- Ошибки провайдера (`401/402/403/422/429`, сеть, гео-блок) не превращаются в 500: запись сохраняется со `status=pending_provider` и русским `provider_error`, сэмплы остаются на диске.
- `synthesize_preview(voice_id, text)` — превью-фраза через тот же путь TTS; ручка `POST /api/voice-lab/clones/{id}/preview` готова, на фронте пока не подключена.
- Ключа ElevenLabs в установке нет (`configured: false`), поэтому живой прогон `voices/add` не делался — прокси/гео-блок проверяются, когда появится ключ.
- `list_remote`/`delete_remote`/`add_samples` из плана первой версии не реализованы.

### 3. API — новый `app/web/routers/voice_lab.py`, префикс `/voice-lab`

**Не под `/api/voices/`**: этот префикс публичный (`app/web/identity.py:177-178`, закреплено тестом `tests/test_identity_middleware.py:132-140`) — клонирование там оказалось бы без токена. `/voice-lab` идёт в `PROTECTED_PREFIXES` (по умолчанию защищён) + проверка роли `admin`, и в `OWNER_UI_PREFIXES` теста `tests/test_front_api_surface.py:33-65`.

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/voice-lab/voices` | реестр + статус из аккаунта, флаги `live`, `used_in_projects` |
| POST | `/api/voice-lab/clones` | multipart `name, description, language, kind, files[]` → IVC → запись реестра |
| POST | `/api/voice-lab/clones/{id}/samples` | добавить или заменить сэмплы |
| POST | `/api/voice-lab/clones/{id}/preview` | `{text}` → mp3 (платно), кэш в `<dir>/preview.mp3` |
| POST | `/api/voice-lab/clones/{id}/use` | `{project_id}` → PATCH `meta.node_step_params.audio.elevenlabs_voice_id` |
| PATCH | `/api/voice-lab/clones/{id}` | имя, описание |
| DELETE | `/api/voice-lab/clones/{id}` | 409 со списком проектов, если используется; `force=true` → soft-delete + удаление в аккаунте |
| POST | `/api/voice-lab/sync` | импорт клонов из аккаунта, пометка пропавших `deleted` |
| GET | `/api/voice-lab/clones/{id}/sample` | отдать загруженный сэмпл файлом |

Общий каталог для выбора — `GET /api/voices/all` в существующем роутере: 9 стандартных + 200 русских + клоны, поля только `id, name, gender, language, source, sample_url` (без себестоимости, путь публичный и read-only). Объявлять ручку **до** `GET /voices/{voice_id}` (`app/web/routers/voices.py:35`), иначе FastAPI примет `all` за id голоса и отдаст 404. После этого UI перестаёт возить каталог в бандле.

### Механики

**Клонирование.** Валидация файлов (mp3/wav/m4a/ogg/flac, суммарно ≤25 МБ, речи ≥30 с) → сохранить в `data/voices/clones/<uuid>/` → `POST /v1/voices/add` → запись в реестр со статусом `ready` → (опционально) платная превью-фраза → голос появился в выборе. Ошибки провайдера не теряют сэмплы: они уже на диске, повтор возможен кнопкой «Создать ещё раз».

**Сохранение.** Сэмплы остаются на диске всегда; реестр хранит внешний id, статус, автора и время; `sync` подтягивает изменения аккаунта и помечает пропавшие `deleted`. Soft-delete, чтобы старые проекты не ломались молча.

**Использование.** Пишем в `meta.node_step_params.audio.elevenlabs_voice_id` — этот путь уже принимает любую строку ≥15 символов (`app/services/elevenlabs_voices.py:88-89`), панель ноды и чат (`audio.set_voice`) пишут туда же. `probe_live_voice_ids` расширяем реестром в обеих ветках, иначе в WaveSpeed-ветке клон считается мёртвым (`app/services/elevenlabs_voices.py:102-109`).

**Удаление.** Сначала проверка использования по проектам: занят — 409 со списком; `force=true` — soft-delete записи, удаление в аккаунте, стирание сэмплов; в UI бейдж «Удалён», в проектах голос работает до перегенерации.

### Деньги

- IVC: точной цены в коде нет. До живого прогона — `unpriced=True` (так леджер честно показывает «генерации без цены», `app/services/media_ledger.py:11-19`), после — ставка в `media_prices.json`.
- Превью и тестовая фраза — по символам, как TTS. Сейчас в проекте три разных ставки за символ: 0.0003 (`app/services/media_spend.py:15`), 0.0001 (`app/services/media_prices.json:76-95`), 0.00015 (`app/services/elevenlabs_api.py:447`). В этом же change свести к одной.
- Суточного потолка трат на медиа нет (`docs/ENGINEERING-POLICY.md:215-218`). Клонирование — ручное действие админа, ограничитель: не больше 10 созданий в сутки на установку (счётчик в реестре).

### Риски

1. Гео-блок: без прокси фича не работает вообще → Этап 0, не код.
2. ToS: клонирование клиентом требует тарифа Scale, поэтому раздел админский.
3. PII: голоса людей на диске — согласие диктора и удаление сэмплов при удалении записи.
4. Провайдер-развилка: при заданном `WAVESPEED_API_KEY` TTS уходит в WaveSpeed (`app/bots/elevenlabs_api.py:212-224`), а WaveSpeed клонов не умеет — клонированный голос работает только при живом ключе ElevenLabs. Решить явным флагом «TTS-провайдер» вместо неявного приоритета.
5. Ключ общий на установку и из файла не применяется на старте (`app/web/routers/profile.py:86-99` вызывается только из `GET /keys`) — клон-ручки должны видеть ключ сразу.
6. Клонирование необратимо расходует лимит тарифа; откат — только удаление голоса.

### Чего в первой версии нет

PVC-обучение (если тариф не даёт), запись с микрофона прямо в UI, шаринг голосов участникам, дообучение PVC новыми сэмплами, перегенерация уже сделанной озвучки.
