## Как проверено и чем

Браузер в песочнице субагента не запускается (Playwright → `spawn EPERM`), поэтому DOM снят
лидом в его браузере и передан мне файлом: **72 семьи, 182 режима, 0 JS-ошибок**
(`web/.tmp-verify/dom-dump-final.json`, скрипт `dump-final.mjs`; в git не кладём). Все DOM-значения
ниже — из этого дампа, снятого лидом, а не мной.

Сверка без браузера:

- `web/.tmp-verify/verify-dom-final.py` — пикер, панель, режимы, цены из дампа против контракта
  и `app/services/kie_catalog.py` (оракул цены — правила прайса);
- `web/.tmp-verify/verify-logic.mjs` — прогон UI-логики (`model-settings.ts`) в node: дескрипторы,
  режимы, `valuesForMode`, локальная цена;
- `web/.tmp-verify/verify-data.py` — каталог ↔ `docs/kie-model-families.json` ↔
  `docs/kie-prices-usd.json`: поля, наценка, валидация, payload;
- `web/.tmp-verify/diag_reach3.py` — достижимость правил цены из полей режима.

## Панель «Параметры»

- Набор полей-чипов сверен по каждому режиму: 0 лишних, 0 недостающих.
- Текст пунктов списков в дампе снят без `value` (только подпись, а подписи бывают с
  пояснением: «1KБазовое»), поэтому 5 предупреждений мягкие: `seedance-1-0/aspect_ratio` (9:21),
  `kling-avatar/resolution`, `seedream-4-5` и `seedream-5` (quality basic/high),
  `gpt-image-1-5` (high) — пункты на месте, расходятся только тексты/значения.
- **4 режима без полей-чипов**: `omnihuman-1-5-image/human-identification|subject-detection`
  (только `image_url`), `recraft/crisp-upscale|remove-background` (только `image`). Панель
  пустая корректно, подпись «**У этого режима нет дополнительных настроек — только промпт и
  файлы.**» — по делу. `kling-avatar/avatar-pro|avatar-standard` получил контрол разрешения.
- Файловые плитки (image_url, audio_url, image) в дамп не входят — это не чипы; проверены
  только именами в контракте и на бэкенде (payload/валидация), в панели — не снимались.

## Цены

Проверено по живой панели (дамп) против правил прайса (`estimate_usd`), допуск $0.011 (дамп
округляет до центов).

**Совпало:**
- 171/171 цена по умолчанию, включая семейства с 4K и аудио;
- 74/74 замера после смены длительности;
- **98/98 замеров после смены разрешения — 0 расхождений**: Seedance 2.0 4K $19.50, Veo 3.1 4K
  $1.13, Gemini Omni 4K $1.31, Kling 3.0 Omni 4K $7.08 — всё по правилам.
- Hailuo 2.3 починен: по умолчанию 6 c → $0.28 (Pro) / $0.19 (Standard), 10 c → $0.56 / $0.31 —
  совпадает с правилами.
- 9 заниженных кейсов теперь дают правило: `kling-avatar` pro 1080p $0.63 / std $0.32,
  `seedream-5-pro` high $0.09 / basic $0.04, `grok-imagine-image/t2i` `enable_pro` $0.03,
  `runway/generate` 10 c $0.19, `grok-imagine-video/extend` 720p $0.17, `grok-imagine-video/upscale`
  $0.19, `gemini-omni-flash-1-2/extend` 720p $0.28 (проверено через `estimate_usd`; quality в
  дампе не кликается).
- «Цена уточняется» — ровно 9 режимов: `gemini-omni/character`, `ideogram-v3/remix`,
  `omnihuman-1-5-image/human-identification|subject-detection` (нет цены в прайсе),
  `gpt-image-2-6/t2i-flare|i2i-flare|t2i-sunburst|i2i-sunburst` (токены),
  `qwen-image/t2i` (мегапиксели). Это честное «уточняется», не FAIL.

**Остался один ценовой вопрос (прайс/бэкенд):** у трёх режимов нет правила на комбинацию
«10 c + 1080p», и при выборе 1080p после 10 c цена **падает** до default:
`hailuo-2-3-i2v/i2v-pro` $0.56 → $0.28, `hailuo-2-3-i2v/i2v-standard` $0.31 → $0.19,
`runway/generate` $0.19 → $0.07. UI показывает ровно то, что отдаёт `estimate_usd`; лечится
правилом на комбинацию или выбором ближайшего (а не минимального) правила.

**«Плоские» замеры:** 39 кликов по длительности/разрешению не изменили цену; все 39 законны
(одна опция разрешения, фиксированная цена за генерацию `unit=gen`, правило не зависит от
выбранного значения, fallback совпадает с ценой) — полный список в JSON (`prices` →
`flat_measurements_total`, `flat_legit`). Режимов, где цена обязана была измениться, нет
(`flat_defects: []`).

## Что не проверено и почему

1. **Смена значения по чипу с повторным открытием панели** — дамп не переоткрывает панель и
   не сверяет active-опцию. Нужен отдельный сценарий.
2. **Ошибки валидации в интерфейсе** — проверены только на бэкенде (required/enum/range/
   max_items/взаимоисключения, все 100 %), в UI блокировки не снимались.
3. **Файловые плитки** (референсы, кадры, аудио) — дамп снимает только поля-чипы.
4. **Цена 4K у токенных режимов** gpt-image-2-6 — не считается без токенов.
5. **Переключение quality в живой панели** (seedream) — дамп кликает только
   duration/resolution; цены по quality проверены через `estimate_usd` (high $0.09, basic $0.04).
6. **Смена цены при переключении режима** — проверено косвенно (цены режимов в дампе разные,
   `modeCount` и наборы полей совпадают), отдельного замера «до/после переключения» нет.
