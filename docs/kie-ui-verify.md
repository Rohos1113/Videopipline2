## Как проверено и чем

Браузер в песочнице субагента не запускается (Playwright → `spawn EPERM`), поэтому DOM снят
лидом в его браузере и передан мне файлом: **72 семьи, 182 режима, 0 JS-ошибок**
(`web/.tmp-verify/dom-dump-final.json`, скрипт `dump-final.mjs`; в git не кладём). Все DOM-значения
ниже — из этого дампа, снятого лидом, а не мной.

Сверка без браузера:

- `web/.tmp-verify/verify-dom-final.py` — пикер, панель, режимы, цены из дампа против контракта
  и `app/services/kie_catalog.py` (оракул цены — правила прайса);
- `web/.tmp-verify/verify-logic.mjs` — прогон UI-логики (`model-settings.ts`) в node: дескрипторы,
  режимы, `valuesForMode`, локальная цена;
- `web/.tmp-verify/verify-data.py` — каталог ↔ `docs/kie-model-families.json` ↔
  `docs/kie-prices-usd.json`: поля, наценка, валидация, payload;
- `web/.tmp-verify/diag_reach3.py` — достижимость правил цены из полей режима.

## Пикер

- «от $X» сверен с `price_from_usd` каталога (округление до центов, допуск $0.005) — совпало
  во всех строках; строк «$0.00» нет.
- Подпись под названием («Стандарт (текст / картинка / видео) · 3 режима») сверена с режимами

- Скрытых семей нет: `veo-3-1` и все `nano-banana*`/`gpt-image-*` видны в общем списке.

## Панель «Параметры»

- Набор полей-чипов сверен по каждому режиму: 0 лишних, 0 недостающих.
- Текст пунктов списков в дампе снят без `value` (только подпись, а подписи бывают с
  пояснением: «1KБазовое»), поэтому 4 предупреждения мягкие: `seedance-1-0/aspect_ratio` (9:21),
  `seedream-4-5` и `seedream-5` (quality basic/high), `gpt-image-1-5` (high) — пункты на месте,
  расходятся только тексты/значения.
- **6 режимов без полей-чипов**: `kling-avatar/avatar-pro|avatar-standard` (только
  `image_url`+`audio_url`+промпт), `omnihuman-1-5-image/human-identification|subject-detection`
  (только `image_url`), `recraft/crisp-upscale|remove-background` (только `image`). По контракту
  полей у них и нет, панель пустая — правильно. Но подпись «**Настройки этого режима
  неизвестны**» врёт: схема известна (промпт и файлы). UX-замечание, владелец — UI-текст.
- Файловые плитки (image_url, audio_url, image) в дамп не входят — это не чипы; проверены
  только именами в контракте и на бэкенде (payload/валидация), в панели — не снимались.

- В дампе 182 режима, `modeCountUi` = контракт у всех 72 семей.
- Панель при открытии семьи может показать не первый режим — UI запоминает последний выбранный

## Цены

Проверено по живой панели (дамп) против правил прайса (`estimate_usd`), допуск $0.011 (дамп
округляет до центов).

**Совпало:**
- 170/171 цена по умолчанию, включая семейства с 4K и аудио;
- 71/73 замера после смены длительности;
- **89/93 замера после смены разрешения — 0 расхождений**: Seedance 2.0 4K $19.50, Veo 3.1 4K
  $1.13, Gemini Omni 4K $1.31, Kling 3.0 Omni 4K $7.08 — всё по правилам.
- «Цена уточняется» — ровно 9 режимов: `gemini-omni/character`, `ideogram-v3/remix`,
  `omnihuman-1-5-image/human-identification|subject-detection` (нет цены в прайсе),
  `gpt-image-2-6/t2i-flare|i2i-flare|t2i-sunburst|i2i-sunburst` (токены),
  `qwen-image/t2i` (мегапиксели). Это честное «уточняется», не FAIL.

**Дефекты (живая панель):**
1. **Hailuo 2.3** `i2v-pro` и `i2v-standard`: по умолчанию `$0.19`, а правила с тиром дают
   $0.2812; при выборе 10 c цена остаётся `$0.19`, хотя прайс требует **$0.5625** (Pro) и
   **$0.3125** (Standard). Причина: правила цены Hailuo 2.3 ключуются полем `mode`
   (tier), которого в форме нет — UI-цена его не видит, бэкенд подставляет дефолт из
   when-правил. Владелец: прайс/бэкенд (`_match_usd_rule`/разложение правил по режимам) +
   UI-цена (передавать tier в values).
2. Правила с ключами, которых нет в форме, остаются недостижимыми: `mode` (29 правил),
   `token_kind` (24), `max_mp` (9), `from_resolution` (3) — итого 40 режимов с частью мёртвых
   правил, 38 — со всеми мёртвыми (симуляция без загрузки файлов; правила `_has_videos`
   достижимы при загрузке видео и в счёт не входят). Практика: 4K у `minimax-h3-image`
   и `kie-image-upscale` считается по дешёвому тарифу, у 4 токенных gpt-image-2-6 цены нет.
   Владелец: прайс + `estimate_usd`.

**«Плоские» замеры:** 40 кликов по длительности/разрешению не изменили цену; 38 законны
(фиксированная цена за генерацию `unit=gen`, опция вне тарифа, отсутствие правила на это
значение) — полный список в JSON (`prices` → `flat_measurements_total`, `flat_legit`).
2 — дефект Hailuo 2.3 выше.

- Отдельный риск: исходник `web/src/lib/model-settings.ts` в рабочем дереве расходится с

  дампе build 577 цена совпала с бэкендом в 170/171, т.е. код в дереве отстаёт от сборки —
  после следующей сборки эти 46 пар надо перепроверить. Владелец: UI/сборка.

## Что не проверено и почему

1. **Смена значения по чипу с повторным открытием панели** — дамп не переоткрывает панель и
   не сверяет active-опцию. Нужен отдельный сценарий.
2. **Ошибки валидации в интерфейсе** — проверены только на бэкенде (required/enum/range/
   max_items/взаимоисключения, все 100 %), в UI блокировки не снимались.
3. **Файловые плитки** (референсы, кадры, аудио) — дамп снимает только поля-чипы.
4. **Цена 4K у токенных режимов** gpt-image-2-6 — не считается без токенов.
5. **Смена цены при переключении режима** — проверено косвенно (цены режимов в дампе разные,
   `modeCount` и наборы полей совпадают), отдельного замера «до/после переключения» нет.
