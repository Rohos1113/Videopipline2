## 5. Сложные формулы с примерами расчёта

### bytedance/seedance-2

- Формула: без видеовхода: тариф × длительность выхода; с видеовходом: тариф × (длительность входа + длительность выхода) — тариф с видео ниже
- Биллинг длительности: `output | with_video: input+output`
- Пример: resolution=720P, output_sec=10, input_video_sec=5, video_input=True → **375 кр** = $1.875 база / $2.3438 клиент (расчёт по прайсу)
